# Security Policy

## Supported versions

`main` is the only supported line while the API is in active development.

## Reporting a vulnerability

Do **not** open a public issue for security problems.

Email **seyedwebpro@gmail.com** with:

- A short description of the impact
- Steps to reproduce, or a proof of concept
- Affected paths, versions, or configuration if known

You should receive an acknowledgement within a few days. Please give time for a fix before any public disclosure.
